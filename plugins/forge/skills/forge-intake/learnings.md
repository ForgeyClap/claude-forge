# forge-intake — learnings

Append-only log of real corrections/preferences learned from actual runs. Read this file before
applying `forge-intake`; add one dated entry (with evidence) after a run that produced a genuine
correction. Never invent an entry — an unsupported "lesson" is worse than no lesson.

- **2026-07-31:** the single-batch question list was replaced by an iterative, one-question-at-a-time
  flow (where the channel allows it), always closing with the meta-question "what should I still
  clarify that I didn't ask?" — per 10 source videos in
  `.claude/forge-research/YT-SWEEP-2026-07-31.md` item 4, which showed one-question-at-a-time produces
  sharper requirements than a batch list. Scope is now recorded in four layers: core / nice-to-have /
  maybe-later (with trigger) / explicitly-out-of-scope. Evidence: `.claude/skills/forge-intake/SKILL.md`
  "## Iteratieve intake" section; batch-list stays the documented fallback for non-interactive runs.
