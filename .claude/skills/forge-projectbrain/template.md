# Template — top-tier project CLAUDE.md

> This is the ANNOTATED structure `forge-projectbrain.cjs::assemble()` follows (proven against it by
> `forge-bin/forge-projectbrain.test.cjs`). `[DETECT:...]` = read from a real file, never assumed.
> `[ADAPT:...]` = an environment rule rewritten to name this project's real tooling, flagged `[<ProjectName>]`.
> `[VERBATIM]` = copied unchanged from the owner's global rules — never paraphrased.
>
> Section order follows the research-driven five-part core framework (description -> stack+versions ->
> commands -> architecture -> conventions) FIRST, before the environment-specific ruleset, boundaries, and
> detail docs — commands sit near the top because they are the highest-ROI content. See `SKILL.md`'s
> "research this method is built on" section for the citations behind every design choice below.

## Anti-Generic Guardrails  *(kept verbatim — the core; the one deliberate exception to the line-budget
## guidance, because verbatim reuse here means every project quotes the SAME trusted rule)*  `[VERBATIM]`
- **Colors:** Never use default Tailwind palette (indigo-500, blue-600, etc.). Pick a custom brand color and
  derive from it.
- **Shadows:** Never use flat `shadow-md`. Use layered, color-tinted shadows with low opacity.
- **Typography:** Never use the same font for headings and body. Pair a display/serif with a clean sans.
  Apply tight tracking (`-0.03em`) on large headings, generous line-height (`1.7`) on body.
- **Gradients:** Layer multiple radial gradients. Add grain/texture via SVG noise filter for depth.
- **Animations:** Only animate `transform` and `opacity`. Never `transition-all`. Use spring-style easing.
- **Interactive states:** Every clickable element needs hover, focus-visible, and active states. No exceptions.
- **Images:** Add a gradient overlay (`bg-gradient-to-t from-black/60`) and a color treatment layer with
  `mix-blend-multiply`.
- **Spacing:** Use intentional, consistent spacing tokens — not random Tailwind steps.
- **Depth:** Surfaces should have a layering system (base → elevated → floating), not all sit at the same
  z-plane.
